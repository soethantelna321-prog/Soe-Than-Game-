# စိုးသန်းဂိမ်း — Android Offline Adventure

ဒီ project ထဲက `app/src/main/assets/index.html` ကို Android WebView ကနေ local file အဖြစ်ဖွင့်တာကြောင့် ဂိမ်းဆော့ရာမှာ အင်တာနက်မလိုပါ။

## အရေးကြီး
ဒီ package က Android Studio project source ဖြစ်ပြီး APK ကို ဒီနေရာမှာ compile မလုပ်ရသေးပါ။ APK တည်ဆောက်ရန် Android Studio နှင့် Android SDK လိုအပ်ပါတယ်။

## APK တည်ဆောက်နည်း
1. Android Studio ကို ကွန်ပျူတာမှာဖွင့်ပါ။
2. `SoeThanAdventure` project folder ကို Open လုပ်ပါ။
3. Gradle sync ပြီးပါက Build > Build Bundle(s) / APK(s) > Build APK(s) ကိုနှိပ်ပါ။
4. APK ကို `app/build/outputs/apk/debug/app-debug.apk` မှာရပါမယ်။
5. APK ကို Tablet ထဲကူးပြီး install လုပ်ပါ။ Unknown apps install ခွင့်ကို ကိုယ်တိုင်ဖွင့်ရန်လိုနိုင်ပါတယ်။
